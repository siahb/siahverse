FIRST CONNECTION

A little setup. Then one click.

  1. 01

    Prepare your Windows computer

    Windows Pro, Enterprise, and Education support incoming Remote Desktop. Enable it in Settings → System → Remote Desktop. For Windows Home, use a VNC server instead.

  2. 02

    Set up your private gateway

    Run the included Guacamole gateway on an always-on server with private network access to your PC. Keep RDP and VNC ports off the public internet.

  3. 03

    Save your computer and secure your login

    Replace the gateway’s initial administrator login, enroll two-factor authentication, and create an RDP connection using your PC’s private address and Windows credentials.

  4. 04

    Connect from DeskHop

    Set your deployed gateway address in DeskHop’s configuration. Keep your PC awake and online, then return here to open your desktop.

Your computer stays yours.

The gateway handles screen, keyboard, and mouse traffic. This page does not store your Windows password. Use remote access only where permitted.
