# Pharm1 Changelog

## v8.3 — 2026-09-28
- Made the Siahverse logo and wordmark link back to Nursing Resources.
- Renamed “Dosage / completion” to “DDC / Fill-ins” throughout the app.
- Added an optional Confidence Rating study tool with Confident / Unsure / Guessing choices.
- Confidence ratings are saved with each session and summarized in Progress, Results, Review, and saved-session cards.
- Added DDC-only built-in tools: a calculator and a unit-conversion reference.
- The conversion reference includes lb↔kg, g↔mg, mg↔mcg, L↔mL, and hr↔min.
- DDC tools only appear on DDC / Fill-ins questions.


## v8.2 — 2026-09-27
- Separated the 19 supplemental study-guide questions from the original 81-question bank.
- Added a Question Bank filter: All 100, Original 81, or Extra 19.
- Chapter and question-type counts now update based on the selected question bank.
- Extra questions are labeled with an “Extra question” badge during quizzes and in review.
- Saved quiz sessions remember whether they were built from All, Original, or Extra questions.


## v8.1 — 2026-09-27
- Added one curated hint per question for all 100 questions.
- Hints are available in Practice Mode only and are limited to one hint per question.
- Hints never identify an answer letter and do not reveal completion answers.
- Hint usage is saved with each quiz session and shown in Progress, Results, and Review.
- Retake Missed starts with a fresh hint allowance for the retake session.


## v8.0 — 2026-09-27
- Expanded the bank from 81 to 100 questions.
- Added 19 supplemental questions for study-guide concepts not directly covered by the original bank.
- Added a persistent Light / Dark mode toggle.
- Added 75- and 100-question quiz-size options.
- Removed repeated “Made with Siahverse” footer/tagline text and shortened setup-page copy.
- Preserved saved sessions, Exam/Practice modes, shuffle, review filters, Retake Missed, and question-type filters.
