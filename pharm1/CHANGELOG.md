# Pharm1 Changelog

## v8.1 — 2026-09-27
- Added one curated hint per question for all 100 questions.
- Hints are available in Practice Mode only and are limited to one hint per question.
- Hints never identify an answer letter and do not reveal completion answers.
- Hint usage is saved with each quiz session and shown in Progress, Results, and Review.
- Retake Missed starts with a fresh hint allowance for the retake session.


## v8.0 — 2026-09-27
- Expanded the bank from 81 to 100 questions.
- Added 19 supplemental questions for study-guide concepts not directly covered by the original bank.
- Added a persistent Light / Dark mode toggle.
- Added 75- and 100-question quiz-size options.
- Removed repeated “Made with Siahverse” footer/tagline text and shortened setup-page copy.
- Preserved saved sessions, Exam/Practice modes, shuffle, review filters, Retake Missed, and question-type filters.
